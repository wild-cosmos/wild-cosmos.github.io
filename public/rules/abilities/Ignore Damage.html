Each time this model suffers an injury, roll a D8: if the value of the roll is equal to or greater than the number in brackets next to this ability, the injury is discarded.

If an effect or ability reduces a model's life without inflicting an injury (for example, if a model is immediately destroyed), the Ignore Damage ability cannot be used to defend against this.

A model with more than one Ignore Damage ability may only use one of these abilities each time they suffer an injury.
