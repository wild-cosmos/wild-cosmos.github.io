This model can be set up after all players have deployed their warbands. If they are set up this way, they may be set up anywhere on the battlefield that is more than 12" away from any enemy models. They must either be set up in such a way that they are not visible to any enemy models, or set up wholly within area terrain. If this is not possible, or if you decide not to set them up on the battlefield, they are instead set up in reserve.
