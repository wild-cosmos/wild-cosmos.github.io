Models must make a morale check in the Resolution Phase if they are within 3" of any visible enemy models with this ability.

Models with the Fearsome ability themselves only make this morale check if any of the visible enemy models within 3" have a Fearsome ability with a greater value (for example, a Fearsome (1) model would only be affected by an enemy model with Fearsome (2) or better).

If a model has more than one Fearsome ability, this is treated as a single ability, adding the values of the individual abilities. For example, a model with two Fearsome (1) abilities is treated as having the Fearsome (2) ability instead.
