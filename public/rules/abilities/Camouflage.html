When an enemy model targets this model with a ranged attack, if this model would be able to make a cover save against the attack, the attacking model incurs a hit roll penalty equal to the number given in brackets next to this ability. This ability is a Stealth ability.

Units can only benefit from Camouflage if every model in the unit has either a Camouflage or a Stealth ability, and every model with only a Camouflage ability would be able to make a cover save against the attack.
