During deployment, this model must be set up in reserve. When they arrive from reserve, they may be set up anywhere on the battlefield, but must be set up within 18" of and visible to the enemy model that you nominated to be marked for death. They must also be set up more than 1" away from any enemy models.

If the model that has been marked for death has been destroyed or is otherwise not on the battlefield, ignore this ability; this model must arrive from reserve using the normal rules for doing so.
